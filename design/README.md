# homes.me CRM — design package (12 November 2026)

Give this whole folder and the master prompt to Claude Code.

1. `homes-me-CRM-master-prompt.md` — the instructions, A to Z. Start here.
2. `web/` — COMPUTER design, 48 clickable pages. Open `web/login.html` in a browser, choose Owner or Agent.
   - `web/ui.css` is the design system (colours, light and dark) for the whole product.
   - `web/research/` — page checklist (`sage.md`), sidebar and interaction rules (`nova.md`), dashboard rules (`atlas.md`).
   - `web/test-reports/` — what 4 broker testers found.
3. `screens/` — PHONE design, 59 clickable screens. Open `screens/Login.dc.html`, choose Agent or Owner.
   The phone screens are drawn in an older green look; the master prompt (section 1.1) says how to build them in the new orange look.
4. PDFs — phone test reports.

Screens marked LATER (Inbox, Chat, Email, Templates) are not part of the first build.
